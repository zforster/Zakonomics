Welcome to **Zakonomics**. This is the first post, a quick tour of what the site supports.

## Writing posts

Create a new post with:

```bash
hugo new content posts/my-new-post.md
```

New posts start as drafts. Set `draft = false` when you're ready to publish.

## Callouts

> Add `+` or `-` after the alert type to make it collapsible.
